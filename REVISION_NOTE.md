# August 2026 revision

We corrected a source-identity alignment error in the development-stage simultaneous-velocity analysis. The correction changes the interpretation of the Joint extension and its composition, addressability, and specificity results. The original rank-4 single-component carrier result, fresh-checkpoint replication, temporal reuse, and position-control result are unchanged.

The corrected evidence shows:

- strong bounded same-object Joint competence using the same Single-derived, Single-only-addressed construction fitted separately for each checkpoint;
- improving family-median composition and rollout fidelity from MF0 to MF1 to MF2, with checkpoint overlap;
- composition-relevant structure in both the rank-4 carrier and its complement, so the carrier is not a demonstrated closed four-dimensional recurrent state.

The active data, reproduction scripts, and identity-keyed semantic test are in [`experiments/joint_velocity_composition/`](experiments/joint_velocity_composition/). Superseded versions remain available through Git history and are not retained as active public artifacts.
